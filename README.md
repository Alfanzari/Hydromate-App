# HydroMate - Daily Hydration Calculator 💧

**HydroMate** adalah aplikasi Android berbasis **Jetpack Compose** yang dirancang untuk membantu pengguna menghitung kebutuhan air minum harian secara personal. Aplikasi ini dibuat untuk memenuhi tugas mata kuliah Rekayasa Perangkat Lunak Aplikasi di Telkom University.

---

## 🚀 Fitur Utama

Aplikasi ini mencakup seluruh kriteria penilaian tugas, di antaranya:
- **Personalized Calculation:** Menghitung kebutuhan air berdasarkan berat badan dan tingkat aktivitas.
- **State Persistence:** Menggunakan `rememberSaveable` sehingga data input (Berat Badan & Switch) tidak hilang saat navigasi balik atau rotasi layar.
- **Material Design 3:** Antarmuka modern menggunakan `Scaffold`, `TopAppBar`, dan `Card`.
- **Localization:** Mendukung dua bahasa (Default: English, Indonesian).
- **Implicit Intent:** Fitur berbagi hasil kalkulasi ke aplikasi pesan/sosial media lain.
- **Responsive UI:** Tampilan yang mendukung *scrollable view* untuk perangkat layar kecil.
